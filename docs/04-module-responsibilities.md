# 12-Phase Module Responsibilities

| Phase | Responsibility | Key outputs |
|---|---|---|
| 01 Fleet | Fleet inventory and vehicle state | Availability, capability, health state |
| 02 Mission | Convert demand into executable missions | Mission/task lifecycle |
| 03 Traffic | Coordinate shared movement | Route/zone decisions, conflict handling |
| 04 Charging | Coordinate energy availability | Charge eligibility and allocation |
| 05 Resource | Model constrained assets | Resource availability |
| 06 Workflow | Orchestrate repeatable processes | Workflow state and transitions |
| 07 Monitoring | Give operators operational visibility | Dashboards, events, alerts |
| 08 Configuration | Manage deployment-specific behavior | Rules, thresholds, parameters |
| 09 Safety | Apply operational safety constraints | Safety states, restrictions, recovery |
| 10 Analytics | Turn event history into insights | KPIs and reports |
| 11 Integration | Isolate external contracts | APIs, adapters, mappings, events |
| 12 Deployment | Operate and evolve the system | Deployment/configuration lifecycle |
