# Safety & Operations

## Safety as a cross-cutting concern

Safety constraints can affect mission validation, task dispatch, traffic decisions, robot execution and recovery workflows.

### Operational safety concepts

- Restricted zones
- Safe-stop / intervention states
- Fault visibility
- Traffic constraints
- Human-robot interaction boundaries
- Recovery workflows
- Safety event logging

## Operations model

The monitoring layer should present a single operational picture: fleet state, mission state, traffic state, charging state and active exceptions.

Operators should be able to understand *what is happening, where it is happening, and which subsystem owns the next decision*.
